# Security policy

WorldKit is an early-development offline toolset. **No independent security audit has been completed.** CI and dependency checks are useful diagnostics, not a security guarantee. Treat untrusted map JSON and image files as untrusted input; review generated drafts before moving them into a game repository.

Report vulnerabilities privately to the repository owner through a contact channel listed on the owner's profile. If no private channel is available, request one in a public issue without exploit details, tokens, or personal data. Include the affected commit, minimal input, impact, and reproduction using your own data. Do not test against live player services; WorldKit has no need to access them.
