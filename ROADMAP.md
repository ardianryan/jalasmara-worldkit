# WorldKit roadmap

This roadmap describes candidate authoring work, not production-game acceptance or release dates.

- [x] Deterministic offline map draft from explicitly mapped source JSON.
- [x] Pixel-grid and palette-preview tools with pinned upstream provenance.
- [x] Synthetic fixtures, local tests, and Gitea verification.
- [ ] Add reviewed preview examples that show draft geometry beside its source, without implying automatic acceptance.
- [ ] Extend connectors and building authoring only after game geometry, migration, and visual gates are specified.
- [ ] Pilot new fauna or character workflows only with explicit provenance, licenses, animation checks, and game-side acceptance.
- [ ] Review dependency updates and commission an independent security assessment before making assurance claims.

See the [game roadmap](https://git.ppti.me/ardianryan/Jalasmara-The-Game/src/branch/main/ROADMAP.md) for gameplay priorities.
