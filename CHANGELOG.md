# Changelog

WorldKit remains at `0.1.0` during early development. New version entries will be added when the Jalasmara project owner requests them. Tool changes between version entries are recorded in Git and pull requests.

## [0.1.0] — 2026-11-10

- Published the original offline OpenWorld-style map-draft adapter and synthetic fixtures.
- Added the attributed Pixel Snapper wrapper and Image-to-Pixel palette-preview workflow.
- Added Gitea verification and curated Jalasmara development screenshots with separate game-art rights.

These tools do not publish game maps or access player data. No independent security audit has been completed.
